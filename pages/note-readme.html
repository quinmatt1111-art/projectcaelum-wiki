Design Notes: Read Me

This category is for design notes. It only appears in authorized mode.

How it works

  • Any page with hidden: true in assets/pages.js is left out of the menu, search and directory for normal visitors.
  • Opening a hidden page directly shows an Access Denied screen.
  • Entering the access code (set as ACCESS_CODE in assets/pages.js) unlocks everything on that device until you end the session.
Not real security. The repo is public, so hidden pages can still be read by anyone who browses the files on GitHub. Fine for design notes and spoilers.

Writing a note

Copy pages/_template-note.html, then add it to pages.js with category: "Design Notes" and hidden: true.

Checklists

  • Use <ul class="checklist"> for to-do lists
  • Add class="done" to a list item to tick it off
